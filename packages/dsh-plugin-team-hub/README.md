# DSH Team Hub Plugin

这是面向 DSH Desktop 的内网项目协作插件，当前版本 `0.1.0-alpha.11`。

`alpha.11` 新增内网签名包自动更新：登录后记住 Hub 地址，每 30 分钟检查版本，通过 Desktop 原生安装器安装新包，重启 Desktop 后生效。面板顶部“插件更新”可查看状态、立即检查或关闭自动更新。旧版须手动安装本版一次，发布说明见 Hub 仓库 `docs/plugin-auto-update.md`。

`alpha.10` 新增项目工作台：动态、计划看板、任务、共享资产、项目指令、46 个 WorkBuddy 专家团目录和服务器周期自动化。部署方式及功能边界见 Hub 仓库 `docs/workbuddy-integration.md`。

`alpha.9` 使用适配浅色/深色主题的半透明玻璃浮动面板。项目管理项收进独立菜单，功能导航显示图标与名称；固定外框与独立内容滚动区避免切换内容时尺寸变化。

`alpha.8` 新增服务器常驻 AgentTeams 协作、Agent 项目成员、多 GitLab 仓库、任务计划批准和执行状态面板。部署与运行边界见 Hub 仓库 `docs/agent-teams.md`。

`alpha.7` 修复预设挂载返回值导致的 `commit is not a function`。复用上下文只写入此次创建的会话；后续普通新会话不继承。项目记忆继续同步和按需检索，但不再自动注入每个会话的系统提示词。已存在会话的历史记录不自动删除。

此版本修复复用会话成功后工作区不显示的问题：在 Agent 创建前导入完整的已结束轮次，保留默认模型和 Agent 预设，保存工作区归属及会话标题后再提示成功。历史内容仍作为 recall 上下文导入，不执行原会话工具调用。升级后重新点击复用即可，旧版本创建的隐藏会话不会自动修改。

支持内网 HTTP 登录、项目创建与邀请、项目成员管理、本地会话/目录绑定、对话增量采集、记忆自动同步、会话内复用和 `team_memory_search` / `team_memory_read` 工具。可信内网试点可以使用 HTTP，登录使用 Hub 账号密码。

模型整理由配套 Hub 服务统一执行，自动发布，无需审核。插件不收集个人模型 API 密钥。选择并关联项目工作区后，该目录中的已有会话与后续新会话自动同步。同步用户和助手的可见文本，保留全部文本分片，不上传隐藏推理、工具执行状态、附件二进制或个人模型凭据。

## 安装

本包需要支持 `node:sqlite` 的 Node.js 22.19+，以及提供 `desktopProfiles`、`webServer`、`sessions` 的 Desktop profile。`systemPrompt` 和 `tools` 可选，没有对应服务时界面仍可用。运行时接口检查基于 DSH `0.1.2-rc.1`。

使用 Desktop 标准插件管理入口安装此精确版本或本地 `.tgz` 包。使用该 Desktop 配套的 DSH CLI 时，可在当前 profile 下运行：

```sh
dsh plugin add /absolute/path/dsh-plugin-team-hub-0.1.0-alpha.11.tgz --profile <当前profile名称>
```

重启 Desktop，点击右下角悬浮球打开“团队项目”。登录后选择项目，在弹窗中选择已有工作区或输入绝对目录路径新建工作区。项目经理、技术总监在成员页直接添加用户，无需邀请令牌或接受邀请。

界面以右上角 440px 宽的非模态浮动面板显示，可折叠、加宽至 640px 或关闭。面板外可继续操作对话；折叠或关闭面板保留当前页面和登录状态，重新打开后继续使用。窄窗口下宽度自动限制在视口内。

配色使用 DeepSeek Harness 的 `--dsw-*` 主题变量；面板内页同步宿主的浅色/深色主题与自定义颜色。未提供主题变量时使用 Harness 默认配色。独立 Hub 管理页面不受插件主题影响。

如果目标安装器只接受 npm 名称，将包上传公司内网 npm 仓库后安装 `dsh-plugin-team-hub@0.1.0-alpha.11`。不要安装到与 Desktop 无关的全局 DSH profile。

## 行为与限制

- 每 2 秒同步；本地 SQLite 保存队列、来源位置和缓存，网络故障后使用相同操作 ID 重试。
- 数据存放在 `~/.dsh-team-plugin/<当前profile目录哈希>/team.sqlite`，不写入 Desktop 管理的 profile 镜像。可通过插件配置的绝对 `dataDir` 覆盖；移动 profile 目录时需要一并迁移该插件数据目录。
- 长期凭据不落盘。关闭 Desktop/profile 或插件卸载后需要重新登录；重登后先重新验证项目权限，再加载记忆。
- 仅采集用户输入和助手可见文本；不采集隐藏推理、插件上下文、工具结果和附件。长文本按 12,000 字符分片上传。
- 缓存最多离线使用 24 小时；登录失效或项目撤权后停止检索。项目记忆通过项目内检索工具按需读取，不自动写入普通新会话。
- 本地队列上限 200 批；满载时保留分片位置，待队列恢复后继续上传，不跳过未上传内容。
- 会话摘要页展示原始文本记录及模型摘要。点击“复用会话”并选择目标工作区后，创建自己的持久化会话，将完整记录作为 Harness recall 上下文导入；来源作者、项目和云端会话 ID 保留。该操作不会自动执行模型或工具，可从工作区中的“复用 · 标题”会话继续提问。
- 已完成真实 Cordis 的插件加载/卸载测试、DSH Client ModuleLoader 格式检查及浏览器插件界面联调。**尚未在真实打包的 Electron Desktop 中完成安装、三种呈现模式和 macOS/Windows 双平台验证，因此当前属于 Alpha 试用包。**

服务端部署、模型配置及本轮未实现项见 Hub 仓库 `docs/team-collaboration.md`。
